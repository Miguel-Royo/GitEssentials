## Repository Structure

```text
classwork-repo/
│
├── data/                  # Datasets used in class (raw files are gitignored)
│   ├── raw/               # Original, untouched source data
│   └── processed/         # Cleaned data produced by my own scripts
│
├── notebooks/             # Jupyter notebooks, one per topic or lesson
│
├── activities/            # In-class activities, numbered by session
│   ├── activity-01/
│   ├── activity-02/
│   └── ...
│
├── homework/              # Graded homework assignments
│
├── projects/              # Larger project work and milestones
│
├── src/                   # Reusable Python modules and helper functions
│
├── outputs/               # Generated figures, tables, and exports
│
├── .gitignore             # Files Git should ignore (data, venv, checkpoints)
├── requirements.txt       # Python dependencies
└── README.md              # You are here
```

**Naming conventions I follow**

| Item | Convention | Example |
|---|---|---|
| Folders | lowercase with hyphens | `activity-05` |
| Notebooks | numbered, descriptive | `03_eda_housing.ipynb` |
| Scripts | lowercase with underscores | `clean_data.py` |
| Branches | `type/short-description` | `feature/add-readme` |

## Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Miguel-Royo/GitEssentials.git
cd GitEssentials
```

### 2. Create and activate a virtual environment

**macOS / Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (PowerShell)**

```powershell
python -m venv venv
venv\Scripts\activate
```

### 3. Install the dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the code

Launch Jupyter to open any notebook:

```bash
jupyter notebook
```

Or run a Streamlit app, if the folder contains one:

```bash
streamlit run app.py
```

> **Requirements:** Python 3.10 or higher and Git installed locally.
